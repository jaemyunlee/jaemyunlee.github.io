# Multiple-Choice Quiz Template

Use this template to present a Korean sentence and allow users to select the correct English translation from a list of options.

## Quiz Example
- **Type**: multiple-choice
- **Korean**: 나는 고양이를 키워요
- **English**: I have [cats, dogs, trees, water]
- **Answer**: cats
- **Explanation**: "cats" means 고양이들.

## Behavior
- Options are listed inside brackets separated by commas.
- Incorrect answers trigger a shake/fade animation and become disabled.
- The user can continue trying until selecting the correct answer.
